### 🚀 Featured Projects & Work

* **Real-Time Hospital Queueing System:** Developed multi-window queueing control panels with live dashboard displays, initially built with **Python/Flask** and later upgraded using **Laravel, WebSockets, and Tailwind CSS**.
* **HR Management System (PDS Profiling):** Built an HR module tailored to Civil Service Personal Data Sheet profiling using **Laravel Livewire** and **PostgreSQL**, handling education, work experience, and family background data.
